## 💻 How to Run Locally

Since this is a client-side static web project, no complex build steps or external dependencies are required.

### Option 1: Python Built-in HTTP Server (Recommended)
Run the following command from the project root directory:

```bash
# Using Python 3
python -m http.server 8000
```
Then open your browser and visit:
```text
http://localhost:8000
```

### Option 2: VS Code Live Server Extension
1. Open the project folder in VS Code.
2. Right-click on `index.html`.
3. Select **"Open with Live Server"**.

### Option 3: Direct File Opening
Simply double-click `index.html` in your file explorer to open it directly in any modern browser.
